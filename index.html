Dados da cooperativa

Tarifa padrão (valor inicial de cada novo mês)

Isto NÃO é mais a tarifa usada em todo cliente/mês — é só o valor que já vem preenchido quando você abre um mês novo em Contas. O que realmente entra no cálculo de cada cliente é a tarifa daquela linha específica, lançada em Contas a partir da conta Copel real do mês dele — porque a tarifa muda ao longo do ano e cada bandeira/reajuste afeta o valor.

Pagamento e emissões

O fator de CO₂ é uma estimativa do fator médio do grid brasileiro (SIN) — ajuste se você tiver uma fonte oficial (ex: MCTI) mais atual. Usados no "Demonstrativo de Energia" de cada cliente.

Projeção

Usada só para estimar o prazo restante no Dashboard — não altera os dados salvos.

Backup e restauração

Baixe um backup regularmente para guardar uma cópia de segurança de todos os dados (clientes, contas, financeiro). "Restaurar backup" SUBSTITUI todos os dados atuais pelo conteúdo do arquivo escolhido — use com cuidado.

Senha de acesso

Senha usada por este navegador para ler e salvar os dados no servidor. Se você limpar os dados do navegador ou abrir em outro dispositivo, ela será pedida novamente.
